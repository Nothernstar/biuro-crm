# BRCRM — CRM sprzedaży dla biura rachunkowego

MVP bez zewnętrznych zależności, gotowe do hostowania na Vercel.

## Funkcje
- dashboard KPI: aktywne leady, MRR, konwersja, wartość pipeline
- pipeline 8-etapowy
- kliknięcie karty przesuwa lead do kolejnego etapu
- lista leadów z wyszukiwaniem i filtrowaniem
- źródła leadów i raporty MRR/ARR
- formularz dodawania leadów
- localStorage — dane pozostają w przeglądarce

## Kolejny etap produkcyjny
Next.js + PostgreSQL/Supabase, logowanie, role, historia zmian, zadania, integracje formularza/e-mail, audyt i backup.
